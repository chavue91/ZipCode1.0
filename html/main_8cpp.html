Detailed Description

Main application to process Zip Code data from CSV or length-indicated file.

Uses CSVBuffer to generate a state-wise table of extreme Zip Codes or convert CSV to length-indicated format.

Uses CSVBuffer to generate a state-wise table of extreme Zip Codes, convert CSV files to length-indicated format, or search records by zip code using in-memory primary key indexing via command-line flags.
