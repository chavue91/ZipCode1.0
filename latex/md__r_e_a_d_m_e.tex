\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysubsection{\texorpdfstring{Description}{Description}}\label{md__r_e_a_d_m_e_autotoc_md2}
This program processes U.\+S. ZIP code data from a CSV or length-\/indicated file and supports both\+:
\begin{DoxyItemize}
\item Generating a state-\/wise summary of extreme ZIP codes.
\item Searching ZIP codes using a fast in-\/memory primary key index via command-\/line flags.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md3}{}\doxysubsection{\texorpdfstring{Features}{Features}}\label{md__r_e_a_d_m_e_autotoc_md3}

\begin{DoxyItemize}
\item Reads ZIP code data from a standard CSV or length-\/indicated format.
\item Converts CSV to a length-\/indicated file with a structured header.
\item Extracts fields such as zip code, city, state, latitude, and longitude.
\item Generates a summary of easternmost, westernmost, northernmost, and southernmost ZIP codes per state.
\item Creates and uses a {\bfseries{primary key index}} in RAM for fast ZIP code lookups.
\item Accepts {\ttfamily -\/z\#\#\#\#\#} flags (e.\+g. {\ttfamily -\/z56301}) from the command line to lookup specific ZIP code records.
\item Includes error handling for malformed input and missing files.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md4}{}\doxysubsection{\texorpdfstring{Files in the Project}{Files in the Project}}\label{md__r_e_a_d_m_e_autotoc_md4}
