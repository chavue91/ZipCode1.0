Detailed Description

Main application to process Zip Code data from CSV or length-indicated file.

Main application to process Zip Code data using blocked sequence set structure.

Uses CSVBuffer to generate a state-wise table of extreme Zip Codes or convert CSV to length-indicated format.

Supports CSV conversion, summary generation, zip code search, record insertion, deletion, and dump features for blocked sequence set files.
