\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Description}{Description}}\label{md__r_e_a_d_m_e_autotoc_md2}
{\ttfamily Zip\+Code3.\+0} is a C++ application that processes U.\+S. ZIP code data in a structured blocked sequence set format. The application supports\+:


\begin{DoxyItemize}
\item Converting CSV data into a {\bfseries{length-\/indicated}} format with metadata.
\item Converting that format into a {\bfseries{blocked sequence set file (.bss)}}.
\item Creating a {\bfseries{primary key index}} of high keys per block.
\item Searching for ZIP code records using an efficient block index.
\item Dynamically {\bfseries{inserting}} or {\bfseries{deleting}} ZIP code records with logging and index updates.
\item Dumping the blocked file {\bfseries{by physical}} or {\bfseries{logical order}}.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md3}{}\doxysection{\texorpdfstring{Features}{Features}}\label{md__r_e_a_d_m_e_autotoc_md3}

\begin{DoxyItemize}
\item Converts CSV → Length-\/\+Indicated → Blocked Sequence Set ({\ttfamily .bss})
\item Generates and uses a {\bfseries{simple key-\/to-\/\+RBN index file}} ({\ttfamily .idx})
\item Efficient in-\/place record {\bfseries{insertion}} and {\bfseries{deletion}}
\item Includes structured {\bfseries{header metadata}}, {\bfseries{record sorting}}, and {\bfseries{record splitting}}
\item Supports {\bfseries{sequential dumps}} of blocks in physical or logical order
\item Fast {\bfseries{primary key search}} using {\ttfamily -\/z\#\#\#\#\#} flags
\item Log messages for {\bfseries{splits, merges, index rewrites}}, and {\bfseries{failures}}
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md4}{}\doxysection{\texorpdfstring{Project Structure}{Project Structure}}\label{md__r_e_a_d_m_e_autotoc_md4}
